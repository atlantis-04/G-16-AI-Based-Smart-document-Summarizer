The Global Interpreter Lock (GIL) in Python is a mutex that protects access to Python objects in CPython. This lock prevents true parallelism in multi-threaded programs because only one thread can execute Python bytecode at a time, even on multi-core systems. The GIL exists because CPython's memory management relies on reference counting, which is not thread-safe without a global lock. For CPU-bound tasks, this means threads won't provide a performance benefit. However, for I/O-bound operations like network requests or file reads, the GIL is released, allowing other threads to run. Alternative Python implementations like Jython and IronPython don't have a GIL, but CPython remains the most popular implementation.

Gradient descent is an optimization algorithm used to minimize loss functions in machine learning by iteratively adjusting model parameters. The algorithm calculates the gradient (partial derivative) of the loss function with respect to each parameter, indicating the direction of steepest increase. Parameters are then updated by moving in the opposite direction of the gradient, scaled by a learning rate that controls step size. Smaller learning rates lead to slower but more stable convergence, while larger rates risk overshooting the minimum. Variants like stochastic gradient descent (SGD) update parameters using individual samples instead of the entire dataset, making training faster and more memory-efficient. Adaptive methods like Adam combine momentum with per-parameter learning rate scaling for improved convergence in practice.

DNS resolution is the process of translating human-readable domain names into IP addresses that computers use to communicate. When you enter a URL in your browser, the client sends a DNS query to a resolver, which typically runs on your Internet Service Provider's servers. The resolver then contacts root nameservers, which direct it to the authoritative nameservers for the specific domain. These authoritative servers return the IP address associated with the domain, which is cached at multiple levels to reduce future lookups. DNS operates over UDP port 53 and is hierarchical by design, with caching at recursive resolvers, local network caches, and the operating system level. This distributed caching system is critical for internet performance and resilience.

Docker is a containerization platform that packages applications with their dependencies into standardized units called containers. Unlike virtual machines, containers share the host operating system kernel, making them lightweight and fast to start—typically taking seconds rather than minutes. Docker containers are built from images defined in Dockerfiles, which specify the base OS, dependencies, and commands needed to run an application. The container ecosystem includes Docker Hub for sharing images and Docker Compose for orchestrating multiple containers as a single application. Containers provide consistency across development, testing, and production environments, solving the "it works on my machine" problem. Industry-wide adoption has made Docker the de facto standard for containerization.

HTTPS/TLS (Transport Layer Security) handshake establishes an encrypted connection between client and server through a multi-step negotiation process. First, the client sends a "Client Hello" with supported cipher suites and a random number, and the server responds with "Server Hello," selecting a cipher suite and providing its certificate. The client verifies the server's certificate against trusted certificate authorities and extracts the public key. Both parties then exchange key material using asymmetric cryptography (like RSA or ECDH) to derive a shared session key. This session key is used for symmetric encryption of all subsequent data, balancing security with performance. Finally, both parties exchange "Finished" messages under the new encryption to verify the handshake integrity and begin secure communication.
